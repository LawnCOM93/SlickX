SlickX bakCopy

차세대 Windows 환경을 위한 최첨단 백업 및 압축 관리 시스템.
프로젝트의 안전을 책임지는 개발자의 동반자.

DEVELOPER'S INTENT

개발자들은 프로젝트 개발 과정에서 수시로 프로젝트를 백업하거나 버전을 관리해야 합니다. 이 과정에서 발생하는 반복적인 복사와 압축 작업을 자동화하고, 더욱 체계적이고 효율적인 버전 관리를 지원하기 위해 SlickX bakCopy가 탄생했습니다.

3 Main Pillars

효율적인 작업을 위해 설계된 3열 구조의 인터페이스입니다.

⚖️

좌측 제어 패널

작업 목록 & 즐겨찾기 (상하 분할)

  • 작업 목록: 대기 중인 백업 태스크를 일괄 관리합니다.
  • 즐겨찾기: 자주 사용하는 경로를 스플릿으로 나누어 하단에 상주 시킵니다.
  • 사이즈 조절: 수평/수직 스플릿을 통해 각 영역의 크기를 자유롭게 조절하세요.
🗂️

중앙 작업 패널

작업 구성 & 파일 트리

  • 파일 브라우징: 소스 타입(폴더/파일)을 감지하고 트리 뷰로 탐색합니다.
  • 모드 프리셋: ZIP/COPY와 토큰의 조합으로 8종의 백업 형식을 제공합니다.
  • 인텍스 자동화: 원본 선택 시 작업명을 자동으로 추출하여 편의성을 높였습니다.
📊

우측 상태 패널

진행 상태 & 로그 리포트

  • 멀티 작업 대기열: 현재 진행률과 남은 작업을 실시간으로 모니터링합니다.
  • 상세 처리 로그: 복사/압축된 개별 파일 리스트를 즉시 확인할 수 있습니다.
  • 완전한 비동기: 백업 중에도 UI는 멈추지 않고 반응합니다.

Quick Start

1

소스/대상 지정: 백업할 항목과 저장될 위치를 정합니다.

2

형식 선택: 압축 혹은 단순 복사, 그리고 라벨 여부를 결정합니다.

3

등록 및 실행: 목록에 추가한 뒤 실행 버튼을 누르면 끝!
